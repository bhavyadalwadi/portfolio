# portfolio

This repo contains an older personal portfolio site for Bhavya Dalwadi. It presents background information, front-end skill highlights, project cards, resume access, and contact prompts in a single-page Bootstrap-based site.

## Why this repo still matters

This is the earlier public-facing tech portfolio site. It is useful as an archive of past positioning, front-end presentation style, and project curation before newer repos became the stronger showcase items.

## What this repo does

- Introduces personal background and hiring-focused messaging
- Shows a project gallery with links to multiple GitHub repositories
- Highlights front-end, JavaScript, design, and database skills
- Provides a downloadable resume call-to-action
- Uses Bootstrap and jQuery for layout and small interactions

## Main files

- `Index.html` - main portfolio page
- `_scripts/script.js` - site interactions
- `_styles/styles.css` - portfolio styling
- `_images/` - visual assets and project thumbnails
